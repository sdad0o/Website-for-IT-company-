# Website for IT Company 🚀

This repository contains a professional and responsive website built for an IT company, showcasing services, portfolio, team, and contact sections with integrated email notifications.

## 📖 Project Overview

This project is designed to create a modern, responsive website tailored for an IT company. The website offers a clean design and smooth user experience, providing key information about the company's services, projects, and team.

### 🎯 Key Features
- **Responsive Design:** Works seamlessly across devices.
- **Comprehensive Sections:** Includes About, Services, Portfolio, Team, Career, Contact, and FAQ sections.
- **Email Integration:** Contact and Career forms send automated emails upon submission.
- **Clean Code:** Well-structured and easy to maintain.
  
---

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Styling:** Custom CSS (No frameworks like Tailwind or Bootstrap)
- **Backend:** PHP (for form handling and email notifications)
